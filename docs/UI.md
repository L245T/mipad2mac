# 界面设计约定

MiPad2Mac 采用 macOS 系统设置式布局，优先使用公开原生组件，不依赖第三方 UI 框架。

## 结构与布局

- 主窗口使用 NSSplitViewController、原生侧栏和统一工具栏标题。侧栏固定 180 pt，不支持收起，不重复展示应用 Logo 与名称。品牌信息保留在关于页。
- 侧栏使用 AppKit NSTableView 和 SF Symbols；控制使用 pencil，应用输入模式使用原生square.stack叠放窗口图标。选中行采用系统 controlAccentColor，失焦采用 unemphasizedSelectedContentBackgroundColor；圆角 9 pt、行高 32 pt，保留原生键盘导航与无障碍语义。
- 页面使用SettingsSection分组、LabeledContent、原生菜单和NSSwitch；应用输入模式采用专用列表分组。右侧滚动内容延伸到固定玻璃顶栏后方，正文顶部留出实际顶栏高度；滚动条由系统 ScrollView 管理，遵循系统显示偏好。常驻竖向轨道使用 NSScroller 公开绘制接口呈现胶囊圆角，滑块及交互仍由 AppKit 处理；自动隐藏样式继续使用系统绘制。
- 页面标题与正文标签共用右侧起点 30 pt（20 pt 外边距 + 10 pt 行内边距）。控制状态与连接操作统一放在首组，成功状态不再在底部重复；等待或失败时在首组保留原因。
- 关联设置放在同一分组，标签在左、值或操作在右。长说明放在分组页脚或问号弹出说明中。
- 状态和选中颜色使用系统语义颜色；分组底色按参考图校准为浅色白度 0.965 / 深色 0.18，并提供增强对比度变体。授权和运行状态同时保留文字，不只依赖颜色表达。原生处理状态为红色建议；只有已启用才显示绿色，等待或失败为橙色。状态旁问号展开当前处理方式的说明，并提供独立的无障碍名称。
- 透明侧栏由NSSplitViewItem自动提供系统材质，跟随窗口激活状态；关闭透明或系统降低透明度时使用纯灰背景，不叠加自绘玻璃。不保证私有系统设置页面的逐像素复刻。

## 说明文字层级

- 设置项名称沿用系统正文字体与主要文字颜色；名称下的补充说明统一使用 callout 和 secondary 语义颜色，左对齐、间隔 3 pt，自然换行，不固定行数。
- 同一规则用于透明侧栏、压力与倾斜、测试监控等两行设置项；组外说明仍使用 footnote。错误与操作前提不降为装饰性说明。
- 根据 Apple 的 Typography 和 Labels 指南区分信息层级，避免通过调低整个控件透明度处理说明文字；保留深色模式的语义颜色适配。
- 应用包声明 zh-Hans 本地化，原生右键菜单与保存面板由 macOS 提供中文文案，不修改用户系统语言。

## 长按右键帮助

“遇到问题，无法触发？”作为长按右键名称下方的附属文字链接，与开关处于同一设置行。链接和开关具有独立可访问性，不将链接嵌入开关标签。长按时间紧随其后。

帮助使用原生 sheet，分段切换“排查步骤”和“兼容设置”。标题、分段控件及完成按钮固定，正文独立滚动；Escape 关闭。打开时根据父窗口内容区域和当前屏幕可见范围确定尺寸，并响应父窗口尺寸及屏幕变化；上限 560×520 pt，保留父窗口底部和屏幕边距，不主动放大父窗口，切换分页不改变外框尺寸。

排查页默认显示三个简短问题/行动摘要，用原生 DisclosureGroup 按需展开细节，保留绘画模式、扩展对照和日志证据边界。三项共用 DisclosureGroupStyle：箭头与标题首行对齐，摘要和正文统一缩进20pt；第二项兼容按钮位于标题右侧常显。展开/收起和箭头旋转使用0.18秒过渡，系统减少动态效果开启时禁用动画。兼容页功能说明和静态网页注意事项保留完整原文。

本轮检查附属链接打开、三项展开、兼容切换、正常关闭及系统缩放前后布局。边缘拖动未成功改变主窗口，未声称已完成精确最小尺寸/默认尺寸矩阵。深色、增强对比度与跨屏仍待实机检查；UI 验证不代表实体笔兼容效果通过。

控制页“虚拟按键”和“手指输入 → 状态”均显示“暂不支持”。右侧原生问号分别说明：小米平板当前固件向Mac提供的笔数据不包含笔杆手势；小米平板当前固件在DP-in连接中根据USB-C厂商标识识别Mac，进入Mac分支后不传输手指触摸数据，应用无法从硬件连接获取并适配。文案直接说明传输限制，不介绍研究方法，也不承诺研发计划或恢复日期；手指输入保持与笔输入同级分组。

## 长按防抖

控制页在长按时间下方显示“长按防抖”。使用系统绘制的 SwiftUI Slider，0–18 每个整数可选，鼠标、方向键和可访问性增减均按整数保存。macOS 26+ 采用原生强调色外观，随系统呈现玻璃材质；macOS 26 尚未实测。标题右侧显示当前值，默认显示“中 · 4（默认）”。滑轨下按实际数值位置标注无 0、低 2、中 4、高 8、极高 12、最高 18，不使用等距六档。次要说明明确容忍抖动与拖动距离的取舍；问号补充 0 仍可静止长按、等待时间独立、自动保存及绘画模式不受影响。关闭长按后滑块禁用，说明仍可查看。旧五档存储名称和值兼容，新增中间整数以数值字符串保存。

## 行为约束

展示层复用既有控制和权限操作。测试监控关闭时停止诊断刷新与新增日志，不停止正常笔输入读取。界面刷新复用已有低频定时器，高频 HID 报文不直接驱动界面重绘。

## 页面与尺寸

默认窗口 780×700 pt，最小 720×580 pt；侧栏 180 pt、正文最小 480 pt 是当前工程参数，不是 Apple 强制规范。正文四周 20 pt；组间 22 pt；组内行垂直内边距 9 pt、水平 10 pt；分组圆角 12 pt。这些是依据用户参考图确定的项目参数，不是 Apple 公布的强制值。下拉菜单按内容宽度收缩、右对齐；开关采用原生switch mini的固有尺寸，不拉伸或缩放。

## 原生控件与新版 SDK

开关使用 SwiftUI Switch 的 mini 尺寸（旧 AppKit 页面统一为 NSSwitch mini），按系统内在尺寸布局；滑块使用SwiftUI Slider regular尺寸与整数吸附绑定，方向键和可访问性每次增减1，采用系统高度，不手工缩放滑钮。原生控件负责 Liquid Glass 外观和按下/切换/拖动反馈，不叠加自绘玻璃层。SwiftUI 刷新仅在状态变化时写回原生控件，避免无关刷新干扰控件追踪动画。

构建明确传入当前选择的 macOS SDK 路径和实际 SDK 版本，并检查 Mach-O 的链接 SDK 与其一致，防止 Swift Build 将部署下限误记为 SDK 导致旧外观。最低系统版本仍为 13.0；新版控件基于 macOS 27 验证，macOS 26 未实测。苹果参考：[Build an AppKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/310/)、[Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)。

## 权限恢复操作指引

权限页在“重新检查”下方提供“系统设置已开启，仍显示未授权？”指引，普通打开默认收起，适用迁移且缺权限时自动展开。展开后按移除旧条目并添加当前应用、返回重新检查两步排列，不要求先退出；只有系统提示需重开时才按提示操作。仅处理仍未授权的项目，提醒不要选中旧版或安装镜像副本。系统控制权限名称按macOS27“设备控制和数据访问”/旧版“辅助功能”展示。恢复指引本身不自动诊断失败原因；适用的签名迁移说明在同页解释授权记录可能失效，不自动重置权限。

## 全控件 SDK 接入检查

主页面的按钮、菜单选择器、步进器、分段选择、开关及滑块使用标准系统控件。侧栏采用 NSTableView sourceList 的原生选择高亮；问号帮助采用 AppKit helpButton 和 NSPopover。旧 AppKit 设置行不再缓存并锁定按钮组宽度，跟随系统内在尺寸变化。

文件/应用选择、导出、警告分别使用 NSOpenPanel、NSSavePanel、NSAlert；不覆盖它们的绘制或玻璃背景。卡片、已确认的折叠排版和圆角滚动槽属于内容布局与用户定制，保留；滚动滑钮仍由系统绘制。测试输入画布是诊断内容，不作为按钮替换。

macOS27已逐页检查控制、权限、测试、设置、关于和长按帮助的排版，以及菜单、帮助浮窗、打开/保存对话框。错误警告分支仅代码核对。macOS26、完整深色/增强对比度/减少动态效果矩阵及VoiceOver全流程仍待实测。

## 防抖单行刻度

滑轨下仅保留一行：无/低/中/高/极高/最高分别位于0/2/4/8/12/18，其余整数用点。移除重复的独立圆点和数字行；当前数值仍显示在标题右侧。系统绘制滑轨和滑钮，文字和点由不接收点击的单行刻度层绘制；绑定四舍五入并限制到0–18整数，方向键／可访问性每次增减1。各系统沿用同一布局，不使用自动Slider刻度。

刻度间距微调：文字和点统一为滑轨下方的16点高单行，间隔4点，避免滑钮覆盖“中”等文字。使用无自动刻度的原生Slider及整数吸附绑定；提供每次1的方向键/可访问性增减，禁用时不响应。刻度层不参与点击，0–18与核心存储不变。

## 顶栏毛玻璃（2026-09-18）
正文滚动区域延伸到顶栏后方，固定标题的背景使用 NSVisualEffectView 的 titlebar 材质与 withinWindow 混合。页面顶部按实际顶栏高度留白，滚动后留白随正文移出；标题保持清晰。主页面显式管理安全区和滚动内容留白；权限申请、签名迁移说明及重新授权指引统一放在主窗口的权限检查页。材质随系统激活状态、外观与降低透明度偏好变化；不手绘模糊、不承诺与系统设置私有实现逐像素一致。

顶栏与侧栏的原生材质使用 0.88 alpha 的公开 maskImage 遮罩，小幅降低材质覆盖强度；文字与控件不改变透明度。这是混合强度调整，不是修改系统模糊半径。开启系统降低透明度时移除遮罩，保持完整材质/不透明回退。

侧栏使用 sourceList 自带的外侧留白；滚动视图贴齐侧栏左右边缘，图标贴齐系统单元格起点，避免叠加旧版手动8pt外边距与8pt图标缩进。图标到文字仍保留8pt。

主页面滚动条单独避让实际顶栏高度，常驻圆角滚动槽从顶栏下方开始；正文仍延伸到毛玻璃背后。常驻滚动条调整实际frame以保持系统滑块追踪，覆盖式使用原生scrollerInsets。关闭透明侧栏时采用完全不透明灰色：浅色模式0.90、深色模式0.16，跟随外观刷新。

## 原生玻璃顶栏（2026-09-18，替代上文顶栏材质）
macOS26及以上的顶栏使用NSGlassEffectView regular，系统统一提供玻璃折射、高光与背景模糊。标题通过contentView承载，不叠加旧NSVisualEffectView或0.88遮罩，不对纯展示标题启用交互响应。旧系统回退原有titlebar材质。侧栏继续使用已确认的较轻材质及纯灰不透明回退；滚动条继续避让顶栏。macOS27浅色滚动已检查，macOS26及其他外观完整矩阵仍待实测。

## 统一平整玻璃（2026-09-18，替代前述顶栏/侧栏材质）
顶栏和透明侧栏共用原生NSGlassEffectView regular，背景边缘向裁切区外延伸20pt以弱化凸起周边；顶栏底部28%做背景透明度渐变，标题独立保持清晰。侧栏不淡出，关闭透明仍显示纯灰。旧系统回退语义NSVisualEffectView。降低透明度时移除顶栏渐变，侧栏走不透明回退。这是公开玻璃API与背景遮罩组合，不是系统设置私有渐变模糊，也不保证逐像素复刻。

## 系统管理侧栏（2026-09-18，替代上文侧栏玻璃）
透明侧栏由NSSplitViewItem(sidebarWithViewController:)自动提供原生材质，不额外叠加NSGlassEffectView或NSVisualEffectView。关闭透明或系统降低透明度时使用已确认的纯灰背景。顶栏仍保留柔化的玻璃与底部过渡。当前macOS27浅色截图呈中性灰，不承诺不同壁纸/激活状态下与系统设置完全一致。


### 权限检查与重新授权

手动启动或从Dock、菜单栏默认重开时，若检测到未授权，直接进入主窗口的权限检查页，不再弹出独立申请窗口。普通登录静默启动仍不抢焦点；需要展示签名迁移说明时，在主窗口权限页显示。设置、更新检查等明确入口保持对应页面。

签名迁移规则从1.0.0的Developer ID构建起启用，保留稳定编号；说明只在适用且尚未确认时显示，解释旧授权记录可能因签名身份变更而无法用于当前应用；未知来源保留条件说明。权限已就绪时注明无需重新操作。“我已了解”只确认说明，不修改系统权限；关闭或隐藏窗口不视为确认。

重新授权指引为两步：在系统设置的对应权限项中点“−”移除旧条目，再点“+”选择当前应用、点“打开”并开启开关；返回MiPad2Mac点“重新检查”。不要求先退出，只有系统提示需重开时才按提示操作。保留定位当前应用的访达按钮。迁移后未授权时默认展开指引，普通权限页仍可手动展开。

未授权状态使用系统红色，已授权保留绿色，并始终显示文字。指引内提供五步操作演示，默认自动播放一轮。步骤序号与当前动作说明始终可见，鼠标指针依次定位旧条目、“−”“＋”、当前应用、“打开”、开关与“重新检查”，点击时显示反馈。原生暂停按钮保持当前步骤，重播从第一步开始。演示仅改变本地示意画面，不调用权限接口。收起指引、切换页面、演示滚出可视区域、隐藏或最小化窗口后停止计时；恢复可见时仅继续原本正在播放的演示，手动暂停不自动恢复。系统开启减少动态效果时改为五个编号静态步骤，不运行动画计时。

## 更新页状态与操作

关于页将“版本更新”和“自动检查”分组。前一组显示渠道、检查结果及当前更新状态，状态旁放对应主操作；下载时在下方显示原生进度条和百分比，取消按钮与状态同行。确认更新和下载阶段可取消，校验文件及安装阶段不提供取消。忙碌时禁用检查、渠道和自动检查设置，防止新检查覆盖当前下载候选。后台检查只提示，不下载或安装。

当前生产信任配置尚未启用，界面显示“手动安装更新”和“前往下载页面”，不展示技术配置项。启用条件及协议保留在UPDATING文档。失败时先显示可重试或手动安装的操作，原始原因放可展开的“详细信息”。下载文件已校验不等于应用签名和安装位置已检查，安装确认中明确后续检查、正常退出、备份及保留设置。

## 应用输入模式

列表逐行显示应用图标、名称及指针／浏览／绘画菜单；原长按排除列表不再单独呈现，旧排除应用按绘画保留。选择自动保存，可添加其他应用，HID菜单同步切换当前应用。浏览对已识别内容及未知普通窗口区域滚动，已识别顶栏／工具栏／输入控件和未知窗口顶部保留指针操作；滚动目标固定在落笔处，光标跟随笔尖。每次落笔的用途保持到抬笔，不按压力中途切换。浏览内容区双击或三击时按住最后一下再拖动保留选字，连续点按由系统双击间隔与落笔距离判定，不修改系统设置；同次拖选不滚动、不触发长按右键，拖选结束后清空点击序列。绘画仍单独选择，压力与倾斜继续遵循全局开关。右键兼容帮助依据同一应用模式显示绘画提示，避免旧名单与新模式冲突。
