# 应用内更新

更新检查继续使用固定GitHub仓库`L245T/mipad2mac`，支持稳定版和Beta渠道。自动检查默认关闭，可选每天、7天或30天；后台检查只更新状态，不下载、不安装，也不抢焦点。

## 当前启用状态

客户端已加入下载、清单验证、安装助手、初始化回执及恢复流程。**生产公钥尚未配置，也没有本功能可用的可信发布清单；当前发行版仍使用Release页面手动安装。**不能将模块测试或本地构建当作线上升级验收。

首个具备更新能力的正式包仍需手动安装。生产信任配置和真实升级包准备好后，用户在“关于 → 版本更新”主动下载；进度可查看，下载可取消。校验通过后，再确认“安装并重新打开”。应用正常退出并释放笔输入，助手完成替换并重新打开原安装路径。安装阶段不能中途取消。

仅支持当前用户能够安全写入的本地安装位置，不提权、不强杀、不安装后台服务。请将应用放在应用程序文件夹，退出其他副本；从DMG、只读卷或不可写位置运行时使用手动安装。首次升级来自旧本地签名版本时，仍先手动安装正式发行包。

## 可信发布清单

Release需提供`mipad2mac-update.json`及最终DMG。客户端只接受预置的Ed25519公钥，不从网络新增信任。清单封装字段为：

| 字段 | 含义 |
| --- | --- |
| `payloadBase64` | 原始UTF-8 JSON载荷字节的Base64 |
| `signatureBase64` | 对上述原始字节签署的64字节Ed25519签名 |
| `keyID` | 客户端预置信任表中的公钥编号 |

先验签，再解析载荷；不能重新序列化JSON后验签。载荷包括：

| 字段 | 要求 |
| --- | --- |
| `schemaVersion`、`installerProtocol` | 当前均为整数1 |
| `repository`、`bundleIdentifier` | 固定为`L245T/mipad2mac`、`org.mipad2mac.app` |
| `releaseID`、`tag` | 与所选GitHub Release一致 |
| `applicationVersion`、`buildNumber` | 与包内版本、数字构建号一致；应用版本必须高于当前版本 |
| `channel` | 正式版为`stable`，预发布为`beta`；稳定渠道不接收Beta |
| `assetID`、`assetName`、`byteLength` | 绑定最终DMG附件，名称以`MiPad2Mac-`开头、`.dmg`结尾 |
| `sha256` | 最终DMG的64位小写十六进制SHA-256 |
| `minimumOS`、`architectures` | 与包内声明/实际架构一致，当前系统和架构须兼容 |
| `publicationSequence` | 正整数、单调递增；不能低于本机已成功初始化更新的最高序号 |
| `targetIdentityProfile` | 仅接受客户端固定的`developer-id-v1`发行者约束 |

Release/附件ID必须在GitHub生成后取得，不能猜测。先完成正式签名、公证、App及DMG票据附加和最终校验，再上传固定字节的DMG、生成并签署清单。私钥由发布者在受保护环境管理，客户端和公开源码只需公钥；本功能不存储发布私钥。

缺清单、未知公钥、签名错误、附件不匹配、降级、同版重构建或未知协议都会回退手动安装，不能放宽校验。最高序号是本机补充防重放记录，不能证明首次安装已取得全球最新版本。

## 下载与安装约束

- 清单上限64KiB，签名载荷上限32KiB，DMG上限1GiB；下载使用磁盘文件，按块计算SHA-256，不将整个DMG读入内存。
- HTTPS下载只接受精确的GitHub及指定附件CDN主机，每次跳转重新检查。国内第三方备用地址仍从Release页面手动使用，不自动信任代理下载。
- 临时文件位于当前用户私有缓存；事务位于私有Application Support目录。安装在目标卷的私有目录暂存，检查空间、路径、文件对象和包内链接，复制保留扩展属性及隔离属性。
- 只读挂载DMG，不执行镜像脚本，不使用镜像内的Applications链接决定安装位置。只接受唯一的`MiPad2Mac.app`。
- 校验固定发行者、Bundle ID、版本、构建号、架构、完整资源和嵌套助手；要求Hardened Runtime及安全时间戳，并在暂存及最终安装位置执行Gatekeeper评估。签名通过本身不代表已公证。
- 独立助手位于`Contents/MacOS/MiPad2MacUpdater`，同一目标互斥。监听旧进程退出事件，正常释放笔状态后再替换；不按PID数字或固定延时猜测退出。
- 使用同卷文件替换并保留唯一旧版备份；替换前后记录并校验文件对象。依据Apple的[文件替换接口](https://developer.apple.com/documentation/foundation/filemanager/replaceitemat(_:withitemat:backupitemname:options:))及[完整签名验证接口](https://developer.apple.com/documentation/security/secstaticcodecheckvalidity(_:_:_:))执行。

## 重新打开与恢复

助手按原安装路径打开新版。核心初始化完成后，主程序写入绑定事务、进程、路径、版本和构建号的回执，再显示迁移说明或权限页；不等待平板连接或权限全部就绪。系统返回“打开成功”不等于初始化完成。

新版仍运行但60秒内未确认初始化时，保留备份并标记待确认，不覆盖回滚。确认新版未运行且备份身份、版本和对象均正确时才能恢复。下次打开可从关于页“查看更新恢复”查看记录或请求恢复；存在其他运行副本时先正常退出。无法确认中断后的磁盘对象时停止，保留材料供手动检查。

恢复只处理本事务应用包，不删除或回滚用户偏好。当前不自动清理备份或未解决事务；累计超过128个事务时停止自动处理，需先检查记录。保持`org.mipad2mac.app`不变，普通覆盖升级保留已有偏好。涉及签名身份变更的授权行为须按实际权限状态检查。

## 发行前验收

隔离测试覆盖原始字节验签、版本/渠道/附件绑定、下载限制、取消、流式摘要、路径链接、同目标互斥、替换、回滚、磁盘对象变化、初始化回执及中断记录。生产启用还需独立完成：

1. 审查并配置生产公钥和真实发行清单，验证升级链及密钥管理。
2. 对含嵌套助手的新包重新正式签名、公证、附加票据并校验最终DMG。
3. 在真实正式安装位置验证下载、退出、重新打开、回执及恢复；验证Gatekeeper含隔离属性的安装行为。
4. 用户实测笔定位、点击/拖动、长按退出释放、压力倾斜，以及换签名后的权限恢复、登录启动和窗口可见性。
