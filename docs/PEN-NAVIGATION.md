# 笔输入模式

控制页的“笔输入模式”和HID菜单提供指针／浏览切换。设置按应用标识保存，重启后保留；未设置的应用使用指针。打开控制窗口前使用的应用会显示在选择框中，也可以选择其他应用。

- 指针：保持点击、拖动、文字拖选和绘画。压力与倾斜开关独立控制。
- 浏览：轻点抬笔后单击，移动笔尖滚动，静止长按右键。关闭长按右键后仍可滚动。
- 浏览器里的画布、选字、拖放或滑块操作，需要先从HID菜单切回指针。
- 绘画排除名单中的应用保持指针和即时落笔，不启用浏览。需要绘画的应用应加入名单。

浏览移动超过6个映射后的逻辑点开始滚动，纵向优先；明显水平移动锁定横向。滚动方向跟随笔尖，固定投递位置在落笔处，抬笔立即结束，没有惯性。小于一个像素的位移累计后输出，不通过丢弃坐标降低报文速率。

同一次落笔不会改成另一种操作。切换设置、前台应用、映射，或暂停、断开、睡眠、退出时，结束旧状态；继续接触不会补发点击。滚动不发送左键拖动或数位笔接触。

测试页的接收窗口可记录实际收到的点击计数和滚动阶段。规则测试和本地接收验证不替代实际网页、PDF、嵌套滚动区和绘画软件的兼容性测试。三击如何选中文字由目标应用决定。
