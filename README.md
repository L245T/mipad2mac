# MiPad2Mac

小米平板 DP-in 的 macOS 笔输入适配工具。**v0.1.12 实验版**，作者：**力利欧 @L245T**。

![MiPad2Mac 图标](assets/branding/mipad2mac-app-icon-v8.png)

将已识别的数位笔 HID 输入转换为系统鼠标操作。视频走原有 DisplayPort 链路，本程序不采集、编码或传输画面，不安装内核扩展。

## 当前能力

- 笔的单击、双击、移动和拖动，指定目标显示器并调整旋转/翻转。
- 首次使用指引、独立权限检查、菜单栏启用/暂停及显示器选择。
- 原生 AppKit 分页界面：控制、诊断、关于与更新。
- 输入速率测试、端到端点击测试页、限定设备的 USB/HID 分段诊断。
- GitHub 正式版本检查：手动检查，或选择启动时每天最多检查一次；自动检查默认关闭，只更新状态，不打断笔操作。仅打开下载页面，不自动下载安装。

**手指输入仍未解决；不支持原生多点触控或向绘画软件输出笔压。** 接收到笔压字段不等于输出了笔压。

## 构建和使用

需要 macOS、Xcode Command Line Tools 和 Swift 6.0 或更新版本。当前在 Apple Silicon / macOS 27.0 (26A428) 验证；最低部署版本设为 macOS 13，不代表已测试所有系统与架构。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open dist/MiPad2Mac.app
# 可选：生成带版本号的 DMG 和 SHA-256 校验文件
bash scripts/build-dmg.sh
```

1. 使用支持视频和数据的 USB-C 线连接平板，进入 DP-in。
2. 在“使用指引 → 权限检查”中分别打开控制权限与输入监控设置。控制权限在 macOS 27 中名为“设备控制和数据访问”，旧系统为“辅助功能”。必要时退出并重新打开应用。
3. 在控制页选择平板显示器，用笔轻点以获得可解析报文，再手动启用鼠标控制。
4. 打开平板测试页验证位置、单击和拖动；暂停后可调整方向。屏幕尺寸显示的是逻辑坐标，不是 DP 物理分辨率。
5. 关闭主窗口后继续运行，可从菜单栏暂停或退出。请正常退出，以释放已按下的鼠标按键。

DMG 中提供应用、Applications 入口及安装说明。退出旧版，将应用拖入“应用程序”，推出映像后运行；不要直接从 DMG 运行。

## 签名

没有配置证书时使用 ad-hoc 签名，重建后可能需要重新授权。可以指定自己已有的代码签名身份：

```sh
MIPAD_SIGN_IDENTITY='你的代码签名证书名称或 SHA-1 指纹' bash scripts/build-dmg.sh
```

也支持 `MIPAD_SIGN_IDENTITY_FILE` 指定仅含身份指纹的文件；默认查找仓库外 `../本地签名证书/signing-identity.txt`。配置存在但为空、或签名失败时停止，不静默更换身份。私钥及密码不得放入源码库。

固定证书、Bundle ID 和 designated requirement 有助于保持权限身份；二进制改变导致 CDHash 改变是正常现象。本地自签不等于 Developer ID 签名或 Apple 公证。其他 Mac 的首次安装与授权仍需独立验证。

## 设备与诊断边界

已观察到 Xiaomi Pad 9 Pro Max `2717:2d05`：数位笔 HID、键盘/相对鼠标 HID，以及一个 class 6 USB 接口。已知笔为 Report ID 3、10 字节。仅精确匹配已知描述符；陌生固件不猜测字段后接管鼠标。详见 [协议记录](docs/DEVICE.md)。

用户已确认启用桥接后的笔单击、跨屏定位和离笔位置修复可用。测得约 232.9 报文/秒，是应用回调速率，不是硬件额定扫描率。描述符没有 Touch Screen/Finger 集合；一次完整 45 秒分段采集在两个 HID 接口均成功打开时，手指阶段为 0 条、笔阶段为 3341 条、丢弃为 0。此证据不覆盖其他 USB 通路。

诊断页可分别运行输入速率测试、鼠标通路检测和 USB/HID 分段监控。分段监控覆盖指定 VID/PID 的全部 HID 输入，包括平板复合键盘原始报文；测试时不要用平板键盘输入私人内容。限制 45 秒、20000 条、8 MiB 报文负载，记录打开错误、丢弃数和提前终止。阶段标签只是操作提示，不是输入来源识别。

不会发送未知 Feature/Output 命令，不是完整 USB 总线抓包。监控会暂停控制，结束后需手动启用。事件“已提交”仅代表调用系统发送接口，目标窗口是否收到应使用测试页或实际应用验证。

用户报告 Windows 和手机连接平板时手指可用；后续需对照正常工作的 Windows 描述符与初始化过程。`scripts/windows/Export-XiaomiInput.ps1` 只读枚举并去除实例序列号，不是 USB 抓包，尚未完成 Windows 实机验证。
