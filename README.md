# MiPad2Mac

面向小米平板9 Pro Max DP-in模式的macOS HID笔输入适配工具，让触控笔在Mac上实现准确定位、点击与拖动。

![MiPad2Mac图标](assets/branding/mipad2mac-app-icon-v8.png)

视频使用原有DisplayPort链路，MiPad2Mac只处理笔输入，不采集、编码或传输画面，也不安装内核扩展。笔与触控板共用系统光标。

**基于macOS 27开发，macOS 26暂未测试。** 最低部署版本为macOS 13，不代表所有系统与架构均已验证。本页说明当前源码；下载包包含哪些功能，以对应Release说明为准。

## 支持范围

| 功能 | 当前状态 |
| --- | --- |
| 笔定位与点击 | 支持目标显示器、单击、双击、三击、拖动和文字拖选；默认跟随系统旋转，也可手动旋转、翻转 |
| 应用笔设置 | 按应用保存指针、浏览或绘画模式；浏览只在识别到的内容区域滚动 |
| 长按右键 | 支持等待时间、防抖容差和鼠标手势扩展兼容设置；绘画模式不触发长按 |
| 压力与倾斜 | 默认开启，可关闭；用户已在macOS 27／Photoshop 2026确认有效，其他环境仍需实测 |
| 手指输入 | 暂不支持。已分析的平板固件在Mac连接模式下不转发手指触摸数据 |
| 虚拟按键 | 暂不支持。已知笔接口未检测到捏、双击或滑动笔杆的可用控制数据 |

当前不提供独立光标或原生多点触控。自动化测试和本地事件验收不能代替常用应用中的实体笔体验；浏览模式、连续点击与绘画回归仍需实测。

## 下载与开始使用

从[GitHub正式版](https://github.com/L245T/mipad2mac/releases/latest)下载DMG和同名SHA-256校验文件。Beta及国内备用下载入口见对应[Release](https://github.com/L245T/mipad2mac/releases)说明；第三方入口的可用性可能变化，请核对GitHub提供的校验值。

1. 正常退出旧版，将MiPad2Mac拖入“应用程序”，推出磁盘映像后从应用程序文件夹启动。普通覆盖升级保留已有偏好；不要直接从DMG运行。
2. 用支持视频和数据的USB-C线连接平板，进入DP-in模式。
3. 手动打开时若缺少权限，软件直接进入主窗口的“权限检查”页。完成授权后点“重新检查”；只有系统提示需要时才重新打开应用。
4. 唯一识别到的MI DISPLAY、受支持的笔接口及权限就绪后，软件自动尝试启用，无需先触笔。没有匹配或出现多个同名屏幕时，请在控制页选择目标显示器和笔设备。
5. 在“测试”页打开测试窗口，核对实际到达的定位、轻点和拖动；再进入常用应用检查手感。

同一次连接中手动暂停后不会自动重开控制；重新连接匹配设备后可再次自动接管，成功后请求系统通知。独占失败不会循环重试。

## 常用设置

### 指针与浏览

在“控制 → 应用笔设置”选择应用和输入模式，也可从HID菜单切换当前应用的模式。选择按应用保存；未知应用默认使用指针。

- **指针**：移动光标，轻点单击，按住移动拖动；支持双击选词、三击选段及文字拖选，具体行为由目标应用决定。
- **浏览**：在识别到的网页或可滚动内容区滑动，光标跟随笔尖；顶栏、工具栏和未识别区域保留指针操作。滚动事件固定在最初落笔位置，默认纵向优先，没有惯性；同一次滚动不发送左键拖动或数位笔接触。轻点仍单击，内容区静止长按按全局设置执行。
- **绘画**：即时落笔，保留拖动及可选压力与倾斜输出，不滚动、不触发长按右键或双右键兼容。

原“不使用长按右键的应用”按绘画模式保留，之后在同一个应用设置中调整。显式选择的新模式优先，旧配置保留。浏览会区分只读文字与可编辑输入框，并识别网页卡片、列表和表格内容；编辑框仍保留拖选。内容区双击或三击时，按住最后一下再拖动可扩展文字选择，本次接触不滚动、不触发长按右键；具体选择行为由目标应用决定。绘画前切为绘画；软件不会自动识别网页画布或仅凭力度猜测操作意图。每次落笔的操作类型保持到抬笔，滚动只投递到原落笔位置。嵌套区域是否向父页面继续滚动由目标应用决定。未提供辅助功能命中查询的应用仍回退为指针，不能保证自动识别其聊天或页面区域。

### 长按右键与防抖

连续点按防抖用于双击、三击的位置判定，与长按防抖分别保存。额外容差可设0–18逻辑点，默认4：落笔间距小于9点、点按中移动小于8点时仍可接续点击；0保留原来的5点／4点门槛。启用额外容差时，连续点击以第一下的位置为基准，避免逐次偏移串成同一序列。数值较大可能合并邻近点击；系统双击时间、实际鼠标移动和开始滚动的门槛保持不变，绘画不使用额外容差。

“控制 → 笔输入”中的长按右键默认开启，等待时间默认0.6秒，可选0.3–2秒。普通指针模式下，轻点在抬笔时单击；保持在防抖范围内达到设定时间后发送右键，移动超出范围则开始拖动并取消本次长按。右键触发后仍可移动光标，抬笔不会再次点击菜单。菜单内容由目标应用提供，并非每个位置都有菜单。

“长按防抖”使用原生整数滑块，可选0–18逻辑点，默认4；名称刻度为无0、低2、中4、高8、极高12、最高18。数值越大，越能容忍抖动，开始拖动也需移动更远。0不容忍实际位移，但完全静止仍可长按；等待时间单独设置。旧五档选择自动保留。

需要即时绘画时，到“应用笔设置”将对应应用设为绘画；旧Photoshop排除选择仍有效。绘画模式和窗口顶栏／工具栏保留即时指针输入，目标无法识别时也不等待长按。切换应用、暂停、断开或修改映射／相关设置会取消待触发的长按。

点击“遇到问题，无法触发？”查看排查说明。需要保留鼠标手势扩展的拦截行为时，可按应用开启兼容选项：长按会间隔约100毫秒发送两次完整右键。兼容模式默认关闭；关闭开关保留名单。两次之间抬笔、移出容差或切换应用等操作会取消第二次右键。

**兼容选项也会影响通过本地路径打开的静态网页。未拦截右键的页面可能出现菜单关闭、重新弹出等异常；遇到此情况，请关闭兼容选项。** 软件不会自动检测或修改浏览器扩展，不保证所有页面兼容。双右键兼容效果仍需实体笔验证；力度触发尚未实现。

### 压力与倾斜

控制页与HID菜单的“压力与倾斜”开关同步，选择自动保存；关闭后使用普通鼠标输出。切换时结束当前笔画，保留控制或暂停状态。

在Photoshop的“形状动态”中，可将大小控制设为“钢笔压力”，使用扁椭圆笔尖并将角度控制设为“钢笔斜度”。已知笔接口实测压力范围为0–8191，倾斜随操作变化；旋转／翻转映射已通过自动化测试，完整硬件组合仍待验收。

### 笔设备、显示器与旋转

内置支持已核实的`2717:2d05`和`18d1:2d05`笔身份；后者还核对厂家、机型及完整已知描述符，不接管该厂商的所有设备。未知描述符不会用于输出输入事件。

“选择笔设备…”只列出笔用途和完整已知描述符均匹配的候选。手动选择只用于本次连接；如需记住，请单独点“保存为自定义笔设备…”并确认，可在设置页删除。保存记录不含序列号；设备名称相同不能绕过身份和描述符检查。这不是通用数位板支持。

手动选择的目标显示器在本次运行中优先于自动选屏；屏幕消失后清除失效选择。目标显示器不跨启动保存。旋转方向默认“跟随系统”，也可选择0°、90°、180°或270°，选择自动保存；手动角度替代系统角度，不叠加，也不检测平板物理姿态。屏幕尺寸显示逻辑坐标，不是DP物理分辨率。

修改显示器、旋转或翻转会结束当前笔画并更新映射，保留原有处理方式。**macOS原生处理下，MiPad2Mac的目标屏幕、旋转和翻转不生效；暂停不等于禁用笔。** 视频显示不受控制开关影响。

## 权限、启动与窗口

“权限检查”页显示控制与事件发送、输入监控的实际检测状态。未授权显示红色，已授权按钮禁用。macOS 27的控制权限称“设备控制和数据访问”，旧系统称“辅助功能”；按钮会打开对应系统设置。

若系统开关已开但软件仍显示未授权，展开下方指引查看演示：在对应权限列表点“−”移除旧条目，再点“+”添加当前安装的MiPad2Mac.app、开启开关，返回点“重新检查”。不要选择旧版或安装镜像中的副本。只有系统提示需重开时才操作；演示不会修改系统权限。适用的签名迁移说明合并显示在此页，不另弹申请窗口。

红色关闭按钮默认隐藏窗口并留在菜单栏HID运行，同时隐藏Dock图标，笔控制继续；可在设置中改为保留Dock或关闭即退出。黄色最小化和绿色全屏使用系统行为。

登录自启动默认关闭，由macOS管理注册与批准状态。“登录时不显示主窗口”默认开启；普通登录可留在菜单栏，手动打开仍显示窗口。若登录项待批准，请进入“系统设置 → 通用 → 登录项与扩展”允许MiPad2Mac。建议先安装到应用程序文件夹，再开启自启动。

## 检查更新

在“关于 → 版本更新”选择稳定版或Beta渠道，手动点“检查更新”。稳定版只检查正式发布；Beta也检查预发布。版本按语义版本号比较，不按发布日期或DMG文件名排序，同版不同构建不视为更新；没有可比较版本时不会声称已是最新版。

“自动检查”默认关闭，可选每天、7天或30天。后台检查只提示，不下载、不安装，也不抢焦点；手动检查不受所选周期限制，但仍遵守更新服务的频率限制。

当前从“前往下载页面”手动下载安装：有候选版本时打开对应Release，否则打开发布列表。应用内下载、安装助手和恢复流程已加入源码，但生产信任配置及可信清单尚未启用，不能视为线上升级已可用。启用条件和恢复约束见[应用内更新](docs/UPDATING.md)。

## 测试与隐私

“测试监控与日志”默认关闭，记住选择。关闭时停止诊断刷新、报文快照、速率测量和新增日志，正常笔控制继续；开启时界面每0.5秒刷新，不按每条笔报文重绘。

测试页提供15秒速率测试、实际事件接收窗口、状态记录、清空和导出。速率是应用回调／有效坐标／事件提交速率，不是硬件扫描率；“已提交”仅表示调用系统发送接口，目标是否收到需用测试窗口或实际应用核对。

笔接口原始采集每段最多30秒、12000条、2 MiB，新采集替换上一段；导出包含最近一段采集及最多200条内存调试记录。关闭监控保留已有记录，不自动落盘；导出由用户选择位置，默认下载文件夹。当前不提供手指诊断、键盘监控或完整USB抓包。

软件不自动上传输入报文、设备信息或诊断文件，没有遥测。更新检查访问固定仓库的GitHub Releases API；启用后的更新下载使用GitHub及指定附件CDN，请求会携带应用版本并暴露正常网络连接信息。提交issue或日志前请移除序列号、个人路径和私人输入。

偏好保存在`~/Library/Preferences/org.mipad2mac.app.plist`，不在应用包内；普通覆盖升级保留。登录项状态由系统管理，显示器选择等未全部持久化。协议及历史研究见[设备记录](docs/DEVICE.md)，其中已移除的旧诊断不作为当前使用指南。

## 构建与开发

需要macOS、Xcode Command Line Tools及Swift 6.0或更新版本；当前开发与验证以Apple Silicon／macOS 27为主。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open dist/MiPad2Mac.app
# 可选：按docs/PUBLISHING.md准备dmgbuild，再生成DMG和校验文件
bash scripts/build-dmg.sh
```

应用只显示版本号，不嵌入源码摘要或Git提交编号。正式安装包按版本命名；Beta安装包可附加已验证的公开提交短SHA，区别同版本构建。代码推送不等于发布安装包，日常构建不自动升版。详见[构建与发布](docs/PUBLISHING.md)。

核心输入与状态逻辑位于`Sources/MiPadCore`，应用界面、HID和事件输出位于`Sources/MiPad2Mac`；更新校验与传输位于`Sources/MiPadUpdateCore`、`Sources/MiPadUpdateTransport`，安装助手位于`Sources/MiPad2MacUpdater`。测试位于`Tests`。界面约定见[UI设计](docs/UI.md)，历史变化见[CHANGELOG](CHANGELOG.md)。
