# MiPad2Mac

面向小米平板 9 Pro Max DP-in 模式的 macOS HID 笔输入适配工具，让触控笔在 Mac 上实现准确定位、点击与拖动。

![MiPad2Mac 图标](assets/branding/mipad2mac-app-icon-v8.png)

将已识别的数位笔 HID 输入转换为系统指针操作，并可传递压力、倾斜及接近/离开事件。视频走原有 DisplayPort 链路，本程序不采集、编码或传输画面，不安装内核扩展。

## 当前能力

- 笔的单击、双击、移动和拖动，指定目标显示器并调整旋转/翻转。
- 监听笔设备与显示器接入通知；唯一的小米平板显示器和受支持笔接口就绪后自动选屏、接管，成功后发送系统通知。同一次连接中手动暂停不会自动重开，重新插入后会再次接管。
- 原生侧栏导航：控制、权限检查、测试、设置、关于；AppKit 分栏与 SwiftUI 分组表单，侧栏不收起，详细说明可通过问号查看。
- 笔输入速率测试、端到端点击测试页。
- GitHub 更新渠道：默认稳定版，仅检查正式 Release；可选 Beta 版，同时检查正式版和预发布版。支持手动检查，或选择启动时各渠道每天最多检查一次；自动检查默认关闭，只更新状态，不打断笔操作。仅打开下载页面，不自动下载安装。

**当前仅支持触控笔输入，不支持手指或原生多点触控。** 控制页提供默认开启、可关闭的压感与倾斜输出，已在 macOS 27 / Photoshop 2026 实测有效，其他软件和系统尚未验证。

测试页集中展示笔输入与速率，支持记录当前状态、查看实际到达平板测试窗口的事件、清空和导出最近 200 条本地记录。

基于 macOS 27 开发，macOS 26 暂未测试。

测试监控默认关闭，可在测试页开启并记住选择；关闭时停止调试刷新、报文快照、速率测量和新增日志，正常笔控制继续。日志导出会让用户选择文件位置，默认打开下载文件夹。关闭方式和自动更新检查等偏好保存在 `~/Library/Preferences/org.mipad2mac.app.plist`，常规覆盖升级保留；登录自启动由系统管理。

## 下载与安装

从 [GitHub 正式版](https://github.com/L245T/mipad2mac/releases/latest) 下载 DMG 和同名 SHA-256 校验文件。国内下载备用入口见该版本的 Release 说明；第三方加速服务的可用性可能变化，请以 GitHub 附件的校验值核对文件。

## 构建和使用

需要 macOS、Xcode Command Line Tools 和 Swift 6.0 或更新版本。当前在 Apple Silicon / macOS 27.0 (26A428) 验证；最低部署版本设为 macOS 13，不代表已测试所有系统与架构。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open dist/MiPad2Mac.app
# 可选：生成带版本号的 DMG 和 SHA-256 校验文件
bash scripts/build-dmg.sh
```

1. 使用支持视频和数据的 USB-C 线连接平板，进入 DP-in。
2. 缺少权限时会弹出独立申请页，也可进入“权限检查”重新检查。未授权的项目可点击申请，已授权按钮禁用。控制权限在 macOS 27 中名为“设备控制和数据访问”，旧系统为“辅助功能”。必要时退出并重新打开应用。
3. 程序默认选择唯一识别到的 MI DISPLAY；权限齐全且已连接匹配描述符的笔接口时自动启用，不必先触笔。没有匹配或出现多个同名屏幕时，请手动选择并启用。
4. 在“控制 → 处理方式”选择“MiPad2Mac 控制”或“macOS 原生处理”。在“测试”页点击“打开测试页”验证位置、单击和拖动；修改目标显示器、旋转或翻转会结束当前笔画并更新映射，保持原来的处理方式；目标暂时不可用时等待重新就绪。屏幕尺寸显示的是逻辑坐标，不是 DP 物理分辨率。
5. 默认点击红色关闭按钮后留在菜单栏 HID 运行并隐藏 Dock 图标。设置中可改为保留 Dock 或直接退出；黄色最小化、绿色全屏保持系统行为。设置页支持登录 Mac 时自启动，并提供系统批准提示和登录项设置入口；“侧栏透明磨砂”开关控制原生侧栏材质，并遵循系统降低透明度设置。

DMG 中提供应用、Applications 入口及安装说明。退出旧版，将应用拖入“应用程序”，推出映像后运行；不要直接从 DMG 运行。

## 更新渠道

在“关于 → 版本更新 → 更新渠道”选择“稳定版”或“Beta 版”，选择会持久保存；菜单栏的“检查更新”也使用同一渠道。切换后点击“检查更新”获取结果，不会自动安装或降级。

稳定版排除 GitHub 标记的 Pre-release 和带预发布后缀的标签；Beta 版包含两者，也包含正式版。支持 `v0.4.0`、`v0.4.0-beta.1` 等语义版本，按版本号排序，不按发布日期排序。下载按钮打开选中的具体 Release 页面。

相同应用版本的不同构建不视为更新；DMG 文件名中的提交编号不参与版本比较。若预发布包也使用纯数字版本，转为同号正式版时不会再次提醒；需要区分同一版本的 Beta 迭代时，应在应用版本和 Release 标签中使用一致的预发布后缀。

## 长按右键

在 MiPad2Mac 控制模式下，控制页“笔输入”提供长按右键开关和长按时间。默认开启、0.6 秒，可在 0.3–2 秒间调整，选择会保存。

普通应用中，轻点在抬笔时发送单击；离落笔位置达到 4 个屏幕逻辑点后开始拖动，并取消本次长按识别。保持在该范围内达到设定时间，发送一次 macOS 标准右键；触发后笔尖仍可移动光标，抬笔不会再次点击菜单。菜单内容由目标应用提供，并非所有位置都有菜单。

“不使用长按右键的应用”默认包含 Photoshop，可添加其他绘画应用。这些应用整体保留即时输入，工具栏等区域也不触发长按；不是自动识别画布或压力。前台应用或落笔目标属于排除名单、或目标无法识别时，均保留即时输入。切换应用、修改设置/映射、暂停或断开会取消待触发的长按。绘画前请把所用应用加入排除名单；力度触发尚未实现。

点击长按右键旁的“无法触发？”可查看排查说明，并按需开启“兼容鼠标手势扩展”。它默认关闭；添加指定应用后，在这些应用中长按会间隔约 100 毫秒连续发送两次完整右键。兼容开关和应用名单会自动保存，关闭开关仍保留名单；绘画排除名单优先。两次之间抬笔、移出容差、切换应用、暂停或修改映射/设置会取消第二次，避免向新目标补发。

**注意：此设置也会影响通过本地文件路径打开的静态网页。未拦截右键的页面可能出现菜单关闭、重新弹出等异常；遇到此情况，请关闭兼容选项。** 软件不会自动检测或修改浏览器扩展，不保证所有扩展和页面都兼容。

长按状态机及兼容配置已通过自动化测试；双右键兼容效果和 Photoshop 绘画回归仍需实体笔验证。

## 压感、倾斜与笔杆诊断

控制页“笔输入”分组中的“压力与倾斜”默认开启，关闭后恢复普通鼠标输出。菜单栏 HID 提供同一开关，两处状态同步，选择会持久保存。切换时结束当前笔画，保持原有控制或暂停状态。虚拟按键仍未映射，笔报文诊断保留在测试页。Photoshop 可在“形状动态”中将大小控制设为“钢笔压力”，使用扁椭圆笔尖并将角度控制设为“钢笔斜度”。

原始笔接口实测压力 0–8191，倾斜 X/Y 随操作变化；绘画软件响应已由用户在 Photoshop 2026 画布确认。旋转/翻转的倾斜映射通过自动化测试，尚未逐项硬件验收。

开启测试监控后可按操作进行 30 秒原始笔报文采集，每段最多 12000 条、2 MiB；导出包含最近一段采集及最多 200 条调试记录，新采集会替换上一段。捏、双击、滑动笔杆在本次已知笔接口采集中未出现额外控制位或新报文，不代表其他接口收不到；目前不映射这些动作。不读取键盘接口，不自动上传日志。

## 开启与不开启控制的区别

- **未开启：macOS 原生处理。** MiPad2Mac 不接管笔，系统仍可能响应笔移动。本机测试中，光标可能留在原来的屏幕，点击与笔尖位置不一定对应；应用内的目标屏幕、旋转和翻转不生效。暂停不等于禁用笔。
- **已开启：MiPad2Mac 控制。** 将笔尖位置映射到所选屏幕，轻点转换为鼠标单击、按住移动转换为拖动，应用内的方向设置生效。笔与触控板共用系统光标，不提供独立光标或手指触控；压感与倾斜默认开启，可在控制页或菜单栏关闭。

关闭窗口默认留在菜单栏继续控制；若设置为关闭即退出，则停止控制。暂停或退出后恢复系统原生处理。视频显示不受控制开关影响。这里的“控制”是用户态输入适配，不是安装内核驱动。

## 设备与诊断边界

已观察到 Xiaomi Pad 9 Pro Max `2717:2d05`：数位笔 HID、键盘/相对鼠标 HID，以及一个 class 6 USB 接口。已知笔为 Report ID 3、10 字节。仅精确匹配已知描述符；陌生固件不猜测字段后接管鼠标。详见 [协议记录](docs/DEVICE.md)。

用户已确认启用桥接后的笔单击、跨屏定位和离笔位置修复可用。测得约 232.9 报文/秒，是应用回调速率，不是硬件额定扫描率。描述符没有 Touch Screen/Finger 集合；一次完整 45 秒分段采集在两个 HID 接口均成功打开时，手指阶段为 0 条、笔阶段为 3341 条、丢弃为 0。此证据不覆盖其他 USB 通路。

手指相关的鼠标通路检测、USB/HID 分段监控及 Windows 采集脚本已从当前版本移除。上面的采集数字属于历史研究结果，不是当前应用功能。笔控制仅打开已知数位笔接口，不读取键盘接口。

笔输入速率是应用层统计。事件“已提交”仅代表调用系统发送接口，目标窗口是否收到应使用测试页或实际应用验证。
