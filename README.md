# MiPad2Mac

面向小米平板9 Pro Max DP-in模式的macOS HID笔输入适配工具，让触控笔在Mac上实现准确定位、点击与拖动。

![MiPad2Mac图标](assets/branding/mipad2mac-app-icon-v8.png)

视频使用原有DisplayPort链路，MiPad2Mac只处理笔输入，不采集、编码或传输画面，也不安装内核扩展。笔与触控板共用系统光标。

**基于macOS 27开发，macOS 26暂未测试。** 最低部署版本为macOS 13，不代表所有系统与架构均已验证。本页说明当前源码；下载包包含哪些功能，以对应Release说明为准。

## 支持范围

| 功能 | 当前状态 |
| --- | --- |
| 笔定位与点击 | 支持目标显示器、单击、双击、三击、拖动和文字拖选；默认跟随系统旋转，也可手动旋转、翻转 |
| 应用输入模式 | 可保存全局默认和应用例外，提供指针、浏览或绘画模式；浏览支持已识别内容和未知普通窗口区域 |
| 长按右键 | 支持等待时间、防抖容差和鼠标手势扩展兼容设置；绘画模式不触发长按 |
| 压力与倾斜 | 默认开启，可关闭；用户已在macOS 27／Photoshop 2026确认有效，其他环境仍需实测 |
| 手指输入 | 暂不支持。小米平板当前固件根据USB-C连接的厂商标识识别Mac；当前Mac分支不传输触摸数据，应用无法从硬件连接获取并适配 |
| 虚拟按键 | 暂不支持。小米平板当前固件向Mac提供的笔数据不包含捏、双击或滑动笔杆等手势数据，应用无法获取并映射为按键 |

当前不提供独立光标或原生多点触控。自动化测试和本地事件验收不能代替常用应用中的实体笔体验。此前微信／微博的滚动、拖选和惯性手感已有用户反馈；新默认规则下的实体笔体验、其他应用、双击稳定性及绘画完整回归仍需实测。

## 下载与开始使用

从[GitHub正式版](https://github.com/L245T/mipad2mac/releases/latest)下载DMG和同名SHA-256校验文件。Beta及国内备用下载入口见对应[Release](https://github.com/L245T/mipad2mac/releases)说明；第三方入口的可用性可能变化，请核对GitHub提供的校验值。

1. 正常退出旧版，将MiPad2Mac拖入“应用程序”，推出磁盘映像后从应用程序文件夹启动。普通覆盖升级保留已有偏好；不要直接从DMG运行。
2. 用支持视频和数据的USB-C线连接平板，进入DP-in模式。
3. 手动打开时若缺少权限，软件直接进入主窗口的“权限检查”页。完成授权后点“重新检查”；只有系统提示需要时才重新打开应用。
4. 唯一识别到的MI DISPLAY、受支持的笔接口及权限就绪后，软件自动尝试启用，无需先触笔。没有匹配或出现多个同名屏幕时，请在控制页选择目标显示器和笔设备。
5. 在“测试”页打开测试窗口，核对实际到达的定位、轻点和拖动；再进入常用应用检查手感。

同一次连接中手动暂停后不会自动重开控制；重新连接匹配设备后可再次自动接管，成功后请求系统通知。独占失败不会循环重试。

## 常用设置

### 应用输入模式

在侧栏“应用输入模式”中，先选择“默认模式”：浏览（推荐）、指针或绘画。初始为浏览，没有应用例外时使用此模式。“应用例外”包含已添加或调整过的应用，以及可编辑、可删除的Photoshop各版本兼容规则。绘画模式排在前面，其余按名称排序；已有明确选择保留。

点“＋”选择本机应用，新添加采用当时的全局默认，重复添加保留原模式。选择自动保存，并与HID菜单同步。选中一行后点“−”，移除该例外后恢复当前默认，不卸载应用或删除右键兼容设置。Photoshop家族规则作用于所有版本，具体版本的明确例外优先；移除家族规则不会移除具体版本记录。绘画用途需单独选择，软件不会自动判断。

修改默认不重写应用例外；有例外的应用继续采用自己的模式。模式变化会结束当前接触和惯性，抬笔后重新落笔生效。应用列表统一为单行图标、名称和模式菜单，Photoshop家族名称为“Adobe Photoshop”。找到本机Photoshop时借用其图标，否则显示规则图标；图标不限定规则范围，该行也不代表某个已安装版本。

| 模式 | 操作 |
| --- | --- |
| 指针 | 轻点单击，按住移动拖动；支持双击、三击与文字拖选，静止长按按全局设置执行 |
| 浏览 | 滑动滚动，轻点单击；双击或三击后，按住最后一下拖动选字，同次拖选不滚动、不触发长按右键 |
| 绘画 | 即时落笔，保留拖动和可选压力／倾斜输出；不滚动、不触发长按或兼容右键 |

已确认的系统打开／保存窗格采用全局默认模式，跳过宿主绘画例外。当前判定要求明确窗格标识、模态角色、相同进程和窗口几何关系；普通画布子窗口继续采用应用例外。Photoshop2026打开窗格已核对元数据，Photoshop另存为及实体笔行为仍需实测。非模态、云保存、自定义窗格或跨进程关系无法确认时不会仅凭“弹窗”放开。

浏览模式持续生效，无需逐次开启。已识别的顶栏、工具栏和输入控件保留普通操作；未知普通窗口区域默认滚动，未知窗口顶部32逻辑点保留拖动。自定义输入框或工具栏仍可能滚动，需要普通拖动时请将此应用设为指针模式。软件不会自动识别网页画布，也不按力度切换模式或占用快捷键。

滚动投递到最初落笔位置，光标跟随笔尖；每次落笔的操作类型保持到抬笔，窗口改变、移动或被遮挡时取消当前滚动，已识别内容与未知区域都核对原窗口。嵌套区域是否向父页面继续滚动由目标应用决定。原“不使用长按右键”的应用按绘画模式保留，可在同一入口调整；新选择优先，旧配置保留。

“笔输入”中的惯性滚动默认开启并自动保存，仅用于浏览滚动；这是全局开关，作用于默认或显式采用浏览模式的应用。快速滑动后抬笔，内容继续滚动并逐渐停止；停稳不续滚，再次落笔立即停止。切换应用、暂停、断连、修改映射或目标失效也会停止。延续距离主要取决于速度，笔压仅小幅调整；横纵方向及已识别／未知区域使用同一逻辑，不改变直接滚动、点击、拖选或绘画。桌面、浮层和无法确认普通应用窗口的区域不启用浏览滚动。

“应用输入模式”页默认模式下方和惯性开关旁的问号提供详细说明。此前用户已在微信／微博确认滚动与拖选正常，并认可惯性手感；新默认规则下的实体笔体验和其他应用仍需实测。

### 笔尖模糊触控

在“控制 → 笔输入”调整按钮点击范围，0–18逻辑点，默认6点，0关闭，设置自动保存。点按小按钮附近时，尝试点击范围内距离笔尖最近的可用按钮；距离按按钮边缘计算，与长按及双击防抖分别设置。

原生窗口的关闭、最小化和绿色按钮使用系统专用属性识别，在浏览、指针、绘画模式及本软件窗口中均可尝试容错，不依赖固定位置。绿色按钮仍执行该窗口原有的缩放或全屏行为；自绘窗口按钮或缺少可靠系统信息时无法保证支持。

普通内容小按钮仍需完整核对，绘画画布不吸附。复杂网页或自绘界面可能无法识别；候选相近、查询不完整、按钮隐藏或被遮挡时保留原始点按，原窗口改变则取消点击。文字和已命中的控件不吸附，顶栏拖动、滚动及长按右键保留原始位置。近按钮点按在抬笔时确认，移动达到原有门槛则按原位置拖动或滚动；改变设置会结束当前接触，抬笔后重新判定。

范围设为0时关闭辅助并跳过新增按钮查询。此功能已有原生按钮接收检查；实体笔手感和第三方应用覆盖仍需实测，尚无外部应用查询耗时或资源开销对比。

### 双击与三击防抖

在“控制 → 笔输入”调整，原“连续点按防抖”改用此名称，设置和数值不变。它容忍连续点按的位置偏移，与长按防抖分别保存；不会改变系统双击时间、实际鼠标移动或开始滚动的门槛，绘画不使用额外容差。

额外容差可选0–18逻辑点，默认4：落笔间距小于9点、点按中移动小于8点时可接续点击；0保留原来的5点／4点门槛。启用额外容差时以第一下的位置为基准，避免逐次偏移串成同一序列。数值过大可能合并邻近点击；具体选择行为由目标应用决定，实体笔双击稳定性尚无单独定量复测结论。

### 长按右键与防抖

“控制 → 长按右键”中的开关默认开启，等待时间默认0.6秒，可选0.3–2秒。普通指针模式下，轻点在抬笔时单击；保持在防抖范围内达到设定时间后发送右键，移动超出范围则开始拖动并取消本次长按。右键触发后仍可移动光标，抬笔不会再次点击菜单。菜单内容由目标应用提供，并非每个位置都有菜单。

“长按防抖”使用原生整数滑块，可选0–18逻辑点，默认4；名称刻度为无0、低2、中4、高8、极高12、最高18。数值越大，越能容忍抖动，开始拖动也需移动更远。0不容忍实际位移，但完全静止仍可长按；等待时间单独设置。旧五档选择自动保留。

需要即时绘画时，到“应用输入模式”将对应应用设为绘画；旧Photoshop排除选择仍有效。绘画模式和已识别的窗口顶栏／工具栏保留即时指针输入。切换应用、暂停、断开或修改映射／相关设置会取消待触发的长按。

点击长按开关下的“遇到问题，无法触发？”查看排查说明；“兼容设置…”可直接进入应用兼容名单。需要保留鼠标手势扩展的拦截行为时，可按应用开启兼容选项：长按会间隔约100毫秒发送两次完整右键。兼容模式默认关闭；关闭开关保留名单。两次之间抬笔、移出容差或切换应用等操作会取消第二次右键。

**兼容选项也会影响通过本地路径打开的静态网页。未拦截右键的页面可能出现菜单关闭、重新弹出等异常；遇到此情况，请关闭兼容选项。** 软件不会自动检测或修改浏览器扩展，不保证所有页面兼容。区域查询不可用时，使用已核对的落笔窗口应用匹配兼容名单；窗口无法确认或已改变时取消长按。双右键兼容效果仍需对应页面的实体笔验证。力度触发尚未实现。

### 压力与倾斜

控制页与HID菜单的“压力与倾斜”开关同步，选择自动保存；关闭后使用普通鼠标输出。切换时结束当前笔画，保留控制或暂停状态。

在Photoshop的“形状动态”中，可将大小控制设为“钢笔压力”，使用扁椭圆笔尖并将角度控制设为“钢笔斜度”。已知笔接口实测压力范围为0–8191，倾斜随操作变化；旋转／翻转映射已通过自动化测试，完整硬件组合仍待验收。

### 笔设备、显示器与旋转

内置支持已核实的`2717:2d05`和`18d1:2d05`笔身份；后者还核对厂家、机型及完整已知描述符，不接管该厂商的所有设备。未知描述符不会用于输出输入事件。

“选择笔设备…”只列出笔用途和完整已知描述符均匹配的候选。手动选择只用于本次连接；如需记住，请单独点“保存为自定义笔设备…”并确认，可在设置页删除。保存记录不含序列号；设备名称相同不能绕过身份和描述符检查。这不是通用数位板支持。

手动选择的目标显示器在本次运行中优先于自动选屏；屏幕消失后清除失效选择。目标显示器不跨启动保存。旋转方向默认“跟随系统”，也可选择0°、90°、180°或270°，选择自动保存；手动角度替代系统角度，不叠加，也不检测平板物理姿态。屏幕尺寸显示逻辑坐标，不是DP物理分辨率。

修改显示器、旋转或翻转会结束当前笔画并更新映射，保留原有处理方式。**macOS原生处理下，MiPad2Mac的目标屏幕、旋转和翻转不生效；暂停不等于禁用笔。** 视频显示不受控制开关影响。

## 权限、启动与窗口

“权限检查”页显示控制与事件发送、输入监控的实际检测状态。未授权显示红色，已授权按钮禁用。macOS 27的控制权限称“设备控制和数据访问”，旧系统称“辅助功能”；按钮会打开对应系统设置。

若系统开关已开但软件仍显示未授权，展开下方指引查看演示：在对应权限列表点“−”移除旧条目，再点“+”添加当前安装的MiPad2Mac.app、开启开关，返回点“重新检查”。不要选择旧版或安装镜像中的副本。只有系统提示需重开时才操作；演示不会修改系统权限。签名迁移说明合并显示在此页，不另弹申请窗口。从1.0.0起，适用的本地签名转正式签名迁移说明保留在权限页；来源无法确认时只显示条件说明，权限已就绪时无需重新操作。“我已了解”仅确认说明，关闭或隐藏窗口不视为确认，普通后续升级不会重复已确认的说明。

红色关闭按钮默认隐藏窗口并留在菜单栏HID运行，同时隐藏Dock图标，笔控制继续；可在设置中改为保留Dock或关闭即退出。黄色最小化和绿色全屏使用系统行为。

登录自启动默认关闭，由macOS管理注册与批准状态。登录启动留在菜单栏，即使缺权限或迁移说明尚未确认，也不主动显示窗口。主动打开时，缺少必要权限才进入权限检查页；权限齐全时保留原页面。迁移说明不会单独触发窗口或切页。可信更新器重启沿用更新前的窗口可见状态。若登录项待批准，请进入“系统设置 → 通用 → 登录项与扩展”允许MiPad2Mac。建议先安装到应用程序文件夹，再开启自启动。

## 检查更新

在“关于 → 版本更新”选择稳定版或Beta渠道，手动点“检查更新”。稳定版只检查正式发布；Beta也检查预发布。版本按语义版本号比较，不按发布日期或DMG文件名排序，同版不同构建不视为更新；没有可比较版本时不会声称已是最新版。

“自动检查”默认关闭，可选每天、7天或30天。后台检查只提示，不下载、不安装，也不抢焦点；手动检查不受所选周期限制，但仍遵守更新服务的频率限制。

当前从“前往下载页面”手动下载安装：有候选版本时打开对应Release，否则打开发布列表。应用内下载、安装助手和恢复流程已加入源码，但生产信任配置及可信清单尚未启用，不能视为线上升级已可用。启用条件和恢复约束见[应用内更新](docs/UPDATING.md)。

## 测试与隐私

“测试监控与日志”默认关闭，记住选择。关闭时停止诊断刷新、报文快照、速率测量和新增日志，正常笔控制继续；开启时界面每0.5秒刷新，不按每条笔报文重绘。

测试页提供15秒速率测试、实际事件接收窗口、状态记录、清空和导出。速率是应用回调／有效坐标／事件提交速率，不是硬件扫描率；“已提交”仅表示调用系统发送接口，目标是否收到需用测试窗口或实际应用核对。

笔接口原始采集每段最多30秒、12000条、2 MiB，新采集替换上一段；导出包含最近一段采集及最多200条内存调试记录。关闭监控保留已有记录，不自动落盘；导出由用户选择位置，默认下载文件夹。当前不提供手指诊断、键盘监控或完整USB抓包。

软件不自动上传输入报文、设备信息或诊断文件，没有遥测。更新检查访问固定仓库的GitHub Releases API；启用后的更新下载使用GitHub及指定附件CDN，请求会携带应用版本并暴露正常网络连接信息。提交issue或日志前请移除序列号、个人路径和私人输入。

偏好保存在`~/Library/Preferences/org.mipad2mac.app.plist`，不在应用包内；普通覆盖升级保留。登录项状态由系统管理，显示器选择等未全部持久化。协议及历史研究见[设备记录](docs/DEVICE.md)，其中已移除的旧诊断不作为当前使用指南。

## 构建与开发

需要macOS、Xcode Command Line Tools及Swift 6.0或更新版本；当前开发与验证以Apple Silicon／macOS 27为主。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open dist/MiPad2Mac.app
# 可选：按docs/PUBLISHING.md准备dmgbuild，再生成DMG和校验文件
bash scripts/build-dmg.sh
```
